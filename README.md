# Introduction to GitHub — Soft Skills Academy

Course work and practice materials from **Soft Skills Academy**: an introductory course on **GitHub** (Croatian title: *Uvod u GitHub*).

This repository is meant for learning version control workflows—cloning, branching, commits, pull requests, and resolving merge conflicts—with small, safe example projects.

## What’s in this repository

| Item | Description |
|------|-------------|
| [`Blank Project.html`](Blank%20Project.html) | A minimal Bootstrap page used to practice collaboration: multiple “programmer” lines and a deliberate conflict scenario, matching typical Git/GitHub exercises. |
| [`csharp-template/`](csharp-template/) | A Visual Studio solution (**DLWMS**) with a WinForms UI and data layer—useful as a larger sample repo for the same Git concepts (ignore build output via `.gitignore`). |

## Prerequisites

- **Git** and a **GitHub** account (as covered in the course).
- For the C# solution: **Visual Studio** (Windows) with workloads for .NET desktop development, or another compatible IDE that can open `.sln` / `.csproj` files.

## Quick start

1. Clone the repository:

   ```bash
   git clone https://github.com/<your-username>/UVOD-U-GITHUB-SOFT-SKILLS-ACADEMY.git
   cd UVOD-U-GITHUB-SOFT-SKILLS-ACADEMY
   ```

2. Open `Blank Project.html` in a browser for the simple HTML exercise.

3. Open `csharp-template/DLWMS.sln` in Visual Studio to work with the .NET sample (restore NuGet packages and build when prompted).
